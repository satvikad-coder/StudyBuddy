# StudyBuddy
StudyBuddy is a project made by a couple of Kode With Klossy Web Dev Scholars! StudyBuddy is a website that offers free resources for exams. It recommends websites that offer free mock tests and tutoring for the SHSAT, SAT, ACT, and even AP exam preparation! Don't waste your time researching; start preparing with StudyBuddy's help!
